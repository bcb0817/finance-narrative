# Windowsでのdaemon自動復帰

`install_daemon_task.ps1` は既存の FinanceNarrativeDaemon タスクを修復する。
アカウントとログオン方式は維持する。5分間隔の起動トリガーとログオン時トリガー、
異常終了時1分間隔・最大10回の再試行を設定する。バッテリー時も継続する。
実行中は IgnoreNew と既存daemonの排他ロックにより二重起動を防ぐ。
古いDownloads配置を指す FinanceNarrativeBot は削除せず無効化する。

管理対象の出力は logs/daemon_managed.log に追記する。
復旧試験はdaemonがwaitingで子タスクを実行していない時に限り、
停止後にタスクの次回起動を確認する。投稿履歴やスケジュール状態を消さない。
夜間投稿停止、予算停止、品質・重複チェックは解除しない。

このタスクは既存のInteractiveログオン方式を維持している。
ログアウト中・電源OFF中・スリープ中の継続稼働は保証しない。
無人での24時間稼働には、別途サービスアカウントまたは常時起動サーバーが必要。
この変更は予算設定の書き換え元を特定・排除するものではない。
