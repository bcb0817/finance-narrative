# レバレッジETFの日次X更新

金融Bot @singa9999 に TQQQ / SOXL / FAS / 1570 を各1回、毎日4件投稿する専用ジョブ。
既存ニュース用デーモンとは独立し、既存API認証と投稿予算・頻度制限を使う。

- 米国: 前日の日本日付に対応する米国市場の引け90分後。通常6:30 JST、冬時間7:30 JST。短縮取引日は前倒し。
- 日本: 当日のJPX引け90分後、通常17:00 JST。
- 休場日も各銘柄の状態を投稿し、休場・新しい確定足なしを明記する。
- Yahooデータ取得後、固定SMA200と既存のリスク配分を計算。研究用バックテストやモデル選択は再実行しない。
- 公開用の派生スナップショットだけを独立したGitチェックアウトから公開する。サイト反映を確認した時点でXへ投稿。
- 投稿には方向、研究用目標比率、根拠、基準日を含める。価格の生データは配信しない。1570の除外理由、期限切れ、データ不足を隠さない。
- 投稿日時・銘柄のSQLite一意制約で重複防止。通信結果不明はuncertainとして保持し、自動再投稿しない。実投稿を照合してから人が解決する。
- 既存の1時間2件・1日30件・月間予算制限で投稿が延期されることがある。上限は引き上げない。日中は次回実行で再判定する。
- データ更新・公開失敗は15分間隔で最大3回。同日分のみ追跡し、翌日に前日の未投稿分をまとめて投稿しない。
- Discord通知や追加の生成AI呼び出しは行わない。

Windowsタスク `FinanceETFSignalsDaily` が1分ごとに `run_etf_daily.ps1` を起動する。
PCが起動し、登録ユーザーがログインしていることが必要。更新時刻以降に復帰した場合はその日の未処理分を実行。

確認: `data/etf_daily_last_run.json`、`data/etf_daily_progress.json`、`data/etf_daily.sqlite`。
プレビュー: `.venv\Scripts\python.exe scripts\etf_daily.py --preview`。
停止: `Disable-ScheduledTask -TaskName FinanceETFSignalsDaily`。

FAS追加: XLFのSMA200を参照し、2022年8月の指数変更後のデータから算出。米国3銘柄で既存の投資・露出・共分散制限を共有する。1時間2件上限のため米国3件は少なくとも2時間帯に分かれる。
