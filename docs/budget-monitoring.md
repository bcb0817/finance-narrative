# 承認予算と停止監視

承認値は `config/approved_budgets.json` に記録する。OpenAI $50、xAI $20、X書き込み $15。
予算の変更はユーザーの承認後に `.env`、承認値、`.env.example` を一緒に更新してdaemonを再起動する。
承認ファイルに秘密情報を入れない。`.env` はGitへ追加しない。

daemonの待機ループで5分間隔に、ディスク上の予算・実行中の予算・承認値を比較する。
外部heartbeatが無効でも動作する。実行タスクが長引くと次の待機ループまで検知が遅れる。
差異、OpenAI予算到達、投稿有効時の24時間投稿なしをDiscordへ通知する。
同じ異常の通知は抑制し、送信失敗は次回監視で再試行する。
`data/budget_watchdog.json` に監視状態、`data/budget_changes.jsonl` に予算数値の変更履歴を残す。
設定を変更した人物やプロセスの特定はできない。APIキーや.env全体は記録しない。
異常を検知しても予算は自動的に増額せず、既存の予算停止処理を維持する。

daemon自身が停止するとこの監視も停止する。PC停止を含む検知には別ホストの外部監視が必要。
